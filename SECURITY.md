# Güvenlik

Güvenlik açıklarını GitHub özel güvenlik bildirimi üzerinden (depo sahibi etkinleştirdiyse) veya depo sahibinin belirlediği özel kanal üzerinden bildirin. Parola, token, VPN profili, kişisel log, disk envanteri veya ekran görüntülerini public issue olarak göndermeyin.

Kurulum motoru sudo ile sistem değişiklikleri yapabilir. AUR kodu üçüncü taraf kodudur. Önizleme değişiklik yapmaz ancak yerel durum kontrolleri gerçekleştirir. Docker yetkileri ve parolaları ile ilgili README uyarılarını okuyun.
